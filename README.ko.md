# Quiet Scanner

**IP가 충돌났을 때, 장비를 뽑았다 꽂지 않고 정리하는 도구.**

English: [README.md](README.md)

---

## 왜 만들었나

CCTV·AV 장비는 공장 초기 IP가 죄다 같습니다. 카메라 여덟 대를 스위치에 물리면
여덟 대가 전부 `192.168.0.13` 이라고 우깁니다.

그런데 **일반 IP 스캐너는 그중 한 대밖에 못 봅니다.** 윈도우의 ARP 표가
IP 하나당 MAC 하나만 저장하기 때문입니다. 나머지 일곱 대는 없는 것처럼 보입니다.

그래서 현장에서는 이렇게 합니다.

> 랜선을 전부 뽑는다 → 한 대만 꽂는다 → 웹 들어가서 IP 바꾼다 →
> 다음 거 꽂는다 → 반복

사다리 위에서 마흔 대를 이렇게 하고 있으면 하루가 갑니다.

**이 도구는 선을 안 뽑고 합니다.**

---

## 어떻게 하나

**1. 충돌을 전부 본다**

OS의 ARP 표를 거치지 않고 ARP 응답 패킷을 직접 받습니다. 같은 IP를 쓰는 장비가
몇 대든 전부 잡힙니다.

```
▼ 192.168.0.13   [충돌 4대]
    BC-AD-28-11-22-33   Hikvision   IP 카메라 / NVR   DS-2CD2143G0-I
    BC-AD-28-44-55-66   Hikvision   IP 카메라 / NVR   DS-2CD2043G2-I
    90-02-A9-AA-BB-CC   Dahua       DVR / NVR         IPC-HDW2431T
    E4-30-22-DE-AD-01   Hanwha      IP 카메라          XNV-6081
```

**2. 한 대만 남기고 격리한다**

`이 장비만 격리` 를 누르면 그 IP를 지정한 MAC 하나에 못박습니다
(정적 ARP). 이제 그 IP로 접속하면 **그 장비 한 대에만** 붙습니다.

**3. 웹으로 들어가 IP를 바꾼다**

격리된 채로 장비 웹페이지를 엽니다. IP를 바꾸고 저장하면 끝. 다음 장비로 넘어갑니다.

선을 한 번도 안 건드렸습니다.

## 다른 스캐너와 뭐가 다른가

| | 일반 IP 스캐너 | Quiet Scanner |
|---|---|---|
| 충돌난 IP 찾기 | 한 대만 보임 | **전부 보임** |
| 한 대씩 격리 | 없음 | **있음** |
| 장비 종류 알아내기 | MAC 제조사까지 | **ONVIF·포트·mDNS·UPnP** |
| 카메라 화면 미리보기 | 없음 | **있음** |

충돌을 *탐지*하는 도구는 몇 개 있습니다. **탐지하고 끝**입니다.
이건 "그래서 지금 이놈 IP를 바꿔라"까지 데려갑니다.

## 기능

**찾기**
- 대역 스캔 (`192.168.0.1-254`, CIDR 둘 다)
- 여러 대역 한 번에 — `192.168.0.1-254, 192.168.1.1-254`
- 충돌 IP 자동 감지 · 맨 위로 정렬
- 스캔할 포트 직접 지정 (`80,443,8000-8010`)
- **빈 IP 보기** — 훑은 대역에서 비어 있는 자리를 묶어서 보여줍니다

**알아내기**
- 제조사 **58,471개** (IEEE 등록부 내장, 인터넷 없어도 동작)
- 장비 사전 — MAC 앞자리로 장비 종류까지
- 호스트명(역DNS) · NetBIOS 이름 · 응답시간 · TTL로 OS 짐작
- mDNS(Bonjour) · SSDP(UPnP)로 장비가 스스로 밝히는 이름·모델·시리얼
- ONVIF로 카메라 확인, 웹 제목·인증 realm으로 모델 추출
- 카메라 화면 미리보기 (ONVIF 스냅샷)
- **스위치 포트 찾기 (SNMP)** — 스위치의 MAC 표를 읽어 이 장비가
  몇 번 포트에 물렸는지 표시합니다. 읽기 전용입니다

**정리하기**
- 한 대씩 ARP 격리 → 웹 접속 → IP 변경
- 비정상 종료로 남은 격리를 다음 실행 때 자동 청소

**남기기**
- **HTML 현장 리포트** — 충돌·장비 목록·빈 IP를 한 장으로. 그대로 인쇄하거나 PDF로
- JSON · CSV · XML 내보내기
- 기준선 저장 후 비교 — 시공 전후로 **뭐가 늘고 뭐가 빠졌는지**
- 검색 · 정렬

## 장비 사전

`Hikvision` 까지는 MAC만 봐도 압니다. 그 이상은 사전이 합니다.

```
BC:AD:28  →  Hikvision  ·  IP 카메라 / NVR
00:05:A6  →  Extron     ·  AV 장비
00:10:7F  →  Crestron   ·  제어기
```

기본으로 **150개 브랜드 / 앞자리 2,600여 개**가 들어 있습니다 — CCTV, AV,
음향, 프로젝터, 네트워크, 프린터, 출입통제, 산업 장비.

처음 보는 장비를 만나면 **우클릭 → 장비 사전에 등록**. 다음 현장부터는
스캔하자마자 이름이 뜹니다.

| 입력한 앞자리 | 적용 범위 |
|---|---|
| `BC-AD-28` (6자리) | 그 제조사 장비 **전부** |
| `BC-AD-28-11-22-33` (12자리) | **이 장비 한 대만** |

사전은 `src/장비사전.json` 파일 하나입니다. 현장에서 직접 등록한 것은
`src/장비사전.내것.json` 으로 따로 쌓여서 저장소에는 안 올라갑니다. 팀끼리 주고받을 수 있고,
저장소에 보태주시면 다음 사람이 덕을 봅니다.

> 계정이나 스트림 주소는 넣지 않습니다. 펌웨어마다 달라서 틀린 값은 없느니만
> 못하고, 공개 파일에 계정을 적을 이유도 없습니다.

## 설치

**필요한 것**

| | |
|---|---|
| Windows 10 / 11 | 64비트 |
| [Npcap](https://npcap.com) | ARP를 직접 다루려면 필요. 설치할 때 **"WinPcap API-compatible mode"** 체크 |
| 관리자 권한 | 격리(정적 ARP)에 필요 |

Npcap은 **끼워 넣지 않았습니다.** 직접 받아 설치하십시오 — 5대까지 무료입니다.
([이유](docs/가져다쓴것.md))

**설치 파일로**

`electron/installer/Quiet Scanner Setup 3.0.0.exe` 를 실행합니다.

**소스에서 빌드**

```
Python 3.12  ·  Node.js LTS  ·  pip install pyinstaller scapy
```

```
빌드하기.bat
```

## 쓰는 순서

1. 인터페이스를 고르고 대역을 확인한 뒤 **대역 스캔**
2. 충돌난 IP가 맨 위에 빨갛게 뜹니다
3. 장비 우클릭 → **장비 정보 검사** — 무슨 장비인지 알아냅니다
4. **이 장비만 격리** → 웹으로 들어가 IP 변경
5. **격리 해제** → 다음 장비
6. 끝나면 **내보내기** 로 현장 문서를 남깁니다

**요령** — 같은 IP로 여러 장비에 붙으므로 브라우저는 시크릿 모드를 권합니다.
안 그러면 이전 장비의 세션이 남아 헷갈립니다.

## 안 되는 것

**Npcap 없이는 충돌 탐지가 안 됩니다.** 윈도우 소켓은 IP 계층 위만 다룹니다.
ARP는 그 아래(2계층)라 드라이버 없이는 손이 닿지 않습니다.
격리·식별·웹 접속은 Npcap 없이도 됩니다.

**같은 대역만 됩니다.** ARP도 mDNS도 라우터를 못 넘습니다. 여러 대역을 한 번에
훑을 수는 있지만, 답하는 것은 같은 스위치에 물려 있는 장비뿐입니다.

**스위치 포트 찾기는 SNMP v2c 읽기가 켜져 있어야 합니다.** 관리형 스위치만 됩니다.
언매니지드 스위치는 자기가 뭘 아는지 말해주지 않습니다.

**mDNS·SSDP는 답하는 장비만 답합니다.** AV 장비는 잘 답하고, CCTV 카메라는
절반 정도입니다. 안 답하면 포트를 두드려 알아냅니다.
