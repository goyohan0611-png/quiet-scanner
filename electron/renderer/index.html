사용 가능한 IP

    스캔에서 응답하지 않은 주소입니다. 할당 전 DHCP 범위와 예약 IP를 확인하십시오.

    IP를 클릭하면 복사합니다.

    연결 확인

    IP 충돌 중에는 다른 장비가 응답할 수 있습니다. 특정 장비만 검사하려면 먼저 분리하십시오.

    약 1초마다 응답을 확인합니다. Ping 응답이 없더라도 장비나 방화벽에서 ICMP만 차단한 경우일 수 있습니다.

    장비 사전

    MAC 앞자리로 제조사와 장비 종류를 등록합니다. 70-B3-D5-21처럼 4바이트도 등록할 수 있고, 전체 MAC은 한 장비에만 적용됩니다.

    이 컴퓨터 보호

    Ubuntu/Linux · CrowdSec가 감지한 공격 IP를 이 컴퓨터의 방화벽에서 차단합니다.

    상태 확인 필요

    관리자 승인 후 보호 구성과 실제 적용 상태를 확인합니다.

    처음 설정하기 · 보호 범위

    CrowdSec 1.6.8 이상과 공식 nftables 방화벽 구성요소가 필요합니다. 공식 저장소를 설정한 뒤 서버에서 다음 패키지를 설치하십시오.

    sudo apt install crowdsec crowdsec-firewall-bouncer-nftables nftables

    공식 방화벽 구성요소 설치 시 기본 서비스가 자동 실행될 수 있습니다. 이 앱은 별도의 Quiet Scanner 서비스만 관리합니다. 다른 서비스의 차단은 보호 모드를 꺼도 유지됩니다.

    CrowdSec에서 이 서버의 SSH·웹 서버 로그 수집과 탐지 규칙을 설정한 뒤 보호 준비를 실행하십시오. 관리에 사용하는 IP는 먼저 아래 예외 목록에 등록하십시오.

    보호를 켜면 앱을 닫거나 서버를 재부팅해도 차단 서비스가 유지됩니다. 끄면 Quiet Scanner 서비스만 멈춥니다. 보호 중 표시는 엔진 연결·IPv4/IPv6 규칙 확인 결과이며, 모든 공격 탐지를 보장하지 않습니다.

    첫 버전은 호스트로 들어오는 통신의 IP 차단을 지원합니다. Docker 전달 트래픽·암호화된 본문 검사·백신 기능은 포함하지 않습니다. CrowdSec의 외부 통신·공유 설정은 해당 엔진 설정을 따릅니다.

    CDN·외부 프록시 뒤의 서비스는 실제 접속자가 방화벽에 직접 보이지 않을 수 있으므로 해당 프록시/WAF의 차단 연동이 필요합니다.

    최근 로컬 차단 결정상태 확인 후 표시

    로컬 탐지 최대 100개 알림의 결정입니다. 외부 차단 목록은 표시하지 않습니다. 방화벽 반영에는 시간이 걸릴 수 있습니다.

    아직 보호 상태를 확인하지 않았습니다.

    허용 예외이 서버의 CrowdSec 전체에 적용

    예외 등록은 해당 IP의 기존 차단 결정을 해제하고 향후 차단을 제외합니다. 신뢰하는 주소만 등록하십시오.
