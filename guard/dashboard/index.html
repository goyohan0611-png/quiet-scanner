SSH 접속 보호 설정

접속을 유지할 관리자 PC의 실제 출발지 IP를 등록해 주세요. 이 주소는 SSH 차단 대상에서 제외해요.

여러 주소는 쉼표나 줄바꿈으로 구분해요.

웹 요청 검사 설정

Ubuntu 기본 Nginx의 직접 접속 구성을 지원해요. 실제 외부 경로 확인이 끝나야 동작 확인 상태가 돼요.

사이트 주소를 한 줄에 하나씩 입력해 주세요.

동작 확인이 기다리는 상태라면

웹 검사는 별도 PC에서 정상 요청과 본문 차단 시험을 보내야 해요. 서버 내부의 확인만으로 외부 경로까지 보호된다고 표시하지 않아요.

외부 확인 방법 보기
  1. 서버의 /etc/quiet-guard/waf/probe-client.json을 확인 PC로 안전하게 옮겨 주세요.
  2. 확인 PC에서 제공된 waf_probe.py와 함께 실행해 주세요.
  3. 각 경로의 정상 요청·본문 차단 시험을 통과하면 상태가 갱신돼요.

현재 개발판은 외부 확인 장치 배치를 자동으로 처리하지 않아요.

포트와 실행 프로그램

로컬 바인딩과 외부 접속 확인은 다른 증거예요.

주소 · 포트프로토콜실행 프로그램접속 범위확인 사항

외부 접속 여부도 확인하려면

서버 소유의 IP와 확인할 포트를 정해 별도 PC에서 접속 시험을 할 수 있어요. 접속 거절·시간 초과만으로 서버 전체가 안전하다고 판정하지 않아요.

외부 시험과 현재 점검 범위

서버에서 quiet-guard exposure prepare --target IP로 요청을 만들고, 외부 PC의 exposure probe 결과를 서버의 exposure import로 가져올 수 있어요.

외부 결과는 운영자가 제공한 한 출발지의 TCP 확인이에요. 컨테이너 내부, DNAT·클라우드 접근 정책, 외부 UDP와 앱 권한은 별도 점검이 필요해요.
