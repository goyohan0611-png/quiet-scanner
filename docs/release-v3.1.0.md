# Quiet Scanner v3.1.0

IP 충돌의 흔한 원인인 무단 공유기를 찾을 수 있도록 DHCP 서버 확인을 추가했습니다.

- **DHCP 서버 확인** 버튼을 누르면 선택한 인터페이스에서 DHCP DISCOVER를 한 번 보내고, 응답한 서버를 모두 표시합니다.
- 서버마다 IP·MAC·제조사와 제안한 주소·게이트웨이·DNS·임대 시간을 보여 줍니다.
- 서버가 2대 이상 응답하면 경고를 표시하고 작업 로그에 남깁니다.
- 주소를 요청만 하고 받지는 않으므로 이 PC의 IP와 서버의 임대 목록은 바뀌지 않습니다.
- 스캔 중에는 DHCP 확인을, DHCP 확인 중에는 스캔과 분리를 시작하지 않습니다.
- DHCP 기능은 처음 사용할 때만 불러오므로 실행 준비 시간은 그대로입니다.

## 설치

Assets의 **Quiet.Scanner.Setup.3.1.0.exe**를 받아 설치하십시오.
Windows 10/11 64비트, Npcap(WinPcap API-compatible mode)이 필요합니다.

## 검증 범위

DHCP 응답 해석·중복 제거·동시 실행 차단 자동 테스트 15건을 추가했고, Windows에서 전체 30건과 종료 처리 테스트를 통과했습니다.
개발 PC에서 실제 공유기의 DHCP 응답 수집을 소스, 설치용 엔진, 패키징된 앱 화면에서 각각 확인했습니다.
DHCP 서버가 2대 이상인 망과 중계(relay)를 거치는 망은 실제 환경에서 확인하지 않았습니다.
