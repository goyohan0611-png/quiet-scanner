# Quiet Scanner 4.0.1

Windows 설치 프로그램에 필수 구성 요소 체크리스트를 추가했습니다.

- **Npcap / Microsoft Edge WebView2 Runtime** 두 항목을 첫 화면에 표시합니다.
- 미설치는 빨간색 **✕ 설치 필요**, 설치 완료는 초록색 **✓ 설치 완료**로 구분합니다.
- 없는 항목의 **설치하러 가기** 버튼으로 공식 다운로드 페이지를 엽니다. WebView2는 Microsoft 공식 Evergreen 설치 프로그램 다운로드로 연결합니다.
- 약 1초마다 실제 설치 상태를 다시 확인합니다. 파일 다운로드만 완료된 상태는 설치 완료로 처리하지 않습니다.
- 두 항목이 모두 설치되면 **다음** 버튼이 활성화됩니다. 이미 설치된 항목은 다시 설치할 필요가 없습니다.
- 실제 파일 설치 직전에도 다시 확인하며, 무인 설치에서는 필수 구성 요소가 없으면 오류로 종료합니다.

4.0.0의 UI, 최신 MAC 사전, 스캔·충돌 분리·DHCP·Ping·TCP 기능은 유지합니다. Npcap 드라이버는 설치 파일에 포함하지 않습니다. 구성 요소를 새로 받으려면 인터넷 연결이 필요합니다.

Windows 10/11 x64 전용이며 관리자 권한이 필요합니다.

## 확인한 항목

- 미설치·일부 설치·모두 설치·제거 후 재확인 상태의 감지 테스트
- 실제 PC의 Npcap 드라이버·API 및 WebView2 등록 정보와의 감지 결과 비교
- 체크리스트의 빨강·초록 전환과 두 항목 완료 시 다음 버튼 활성화

검증 과정에서 이 PC의 Npcap이나 WebView2를 제거하지 않았습니다. 미설치 상태의 화면 전환은 별도로 컴파일한 테스트용 상태로 확인했습니다.
