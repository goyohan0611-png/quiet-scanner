# Quiet Scanner v3.0.3

기사들이 빠르게 준비하고, 장비를 바로 찾으며, 분리·해제를 확실히 확인하도록 개선했습니다.

- 필요한 패킷 모듈만 불러오고, IP·서브넷을 Windows에서 직접 조회해 준비 시간을 단축했습니다.
- ARP 응답이 들어오는 즉시 목록에 표시합니다. 스캔이 끝날 때까지 기다릴 필요가 없습니다.
- 무응답 주소 재확인과 응답 IP의 추가 MAC 재확인을 수행합니다.
- 내 PC IP에 다른 장비가 응답해도 자기 MAC을 함께 기록해 충돌을 놓치지 않도록 했습니다.
- 분리 후 Windows 이웃 테이블의 실제 MAC·고정 상태를 확인합니다.
- 해제 확인 실패 시 기존 상태와 복구 기록을 유지하고 다른 장비 분리·재스캔을 막습니다.
- 스캔 중 인터페이스 변경과 분리 작업을 막고, 다음 스캔 시작 전에 실제 인터페이스 주소·인덱스를 다시 읽습니다.
- 정상 종료 시 분리 해제를 시도하며, 엔진이 멈추면 대기 시간을 제한하고 복구 기록을 남깁니다.

## 설치

Assets의 **Quiet-Scanner-Setup-3.0.3.exe**를 받아 설치하십시오.
Windows 10/11 64비트, Npcap(WinPcap API-compatible mode)이 필요합니다.

## 검증 범위

실패 경로·사전·응답 표시 자동 테스트와 종료 처리 테스트를 통과했습니다.
개발 PC에서 실제 공유기 ARP 응답의 즉시 수집도 확인했습니다.
물리 장비의 IP 변경·분리 쓰기 작업은 자동 테스트에서 수행하지 않았습니다.
실행 준비 시간은 PC와 Npcap 환경에 따라 달라집니다.
