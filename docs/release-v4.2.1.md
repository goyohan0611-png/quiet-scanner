# Quiet Scanner 4.2.1 — Windows 분리 안정성 수정

Windows에서 장비를 분리할 때 `분리 설정 실패 (Windows 1168)`이 표시되는 경우의 처리를 보완했습니다. Windows용 수정 배포이며, macOS·Linux는 기존 [4.2.0 설치 파일](https://github.com/goyohan0611-png/quiet-scanner/releases/tag/v4.2.0)을 사용합니다.

## 변경 사항

- 현재 인터페이스 번호에 대응하는 Windows 식별자(LUID)를 확인한 뒤 ARP 항목을 조회·변경합니다.
- 조회 후 동적 ARP 항목이 사라지거나 다시 생겨도 상태를 재확인하고 제한된 횟수로 재시도합니다.
- 기존 항목 수정이 1168로 실패하면 다시 조회합니다. 여전히 동적인 경우 해당 IP의 캐시 항목만 제거하고 선택한 MAC으로 재등록합니다. 재확인된 정적 항목은 덮어쓰지 않습니다.
- 실제 고정 MAC과 영구 상태를 다시 읽어 확인한 경우에만 분리 성공으로 처리합니다.
- 권한 부족, 인터페이스·ARP 항목 없음 등 오류를 구분하고 IP와 인터페이스 번호를 표시합니다.
- 스캐너 배포에는 보호 모드 버튼·화면·실행 코드를 포함하지 않습니다. 보호 기능은 별도 Quiet Guard 프로젝트에서 개발합니다.

## 설치와 확인

기존 앱을 종료하고 `Quiet.Scanner.Setup.4.2.1.exe`를 설치합니다. 인터페이스 새로고침 → 재스캔 → 장비 분리 순서로 확인하십시오. 앱 식별자는 유지하며 사용자 사전과 설정을 초기화하지 않습니다. Windows 관리자 권한·Npcap·WebView2 요구사항은 유지합니다.

## 검증 범위

Windows Rust 테스트 39개와 Clippy 검사를 통과했습니다. ARP 항목 소멸·재등장, 기존 정적 항목 보호, 재시도 제한, 쓰기 후 검증 실패를 성공으로 처리하지 않는 회귀 검사를 포함합니다. Tauri 통신 연결 검사와 Windows 설치 파일 빌드도 수행했습니다.

이 검사는 현장의 USB 네트워크 어댑터와 중복 IP 장비에서 반복 분리·해제가 해결됐다는 실측 결과를 대신하지 않습니다. 현장 재확인은 필요합니다. macOS·Linux 바이너리는 이번 버전에서 새로 배포하지 않습니다.

릴리스에 첨부한 `SHA256SUMS.txt`로 설치 파일 해시를 확인할 수 있습니다.
