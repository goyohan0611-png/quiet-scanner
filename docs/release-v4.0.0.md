# Quiet Scanner 4.0.0

Windows 현장에서 장비를 빠르게 찾고 IP 충돌을 처리하는 흐름에 집중한 버전입니다.

## 변경 사항

- Electron·Python 실행 구조를 Rust·Tauri 2로 전환했습니다.
- 발견한 장비를 바로 표시하고, 무응답 주소와 동일 IP의 추가 MAC 주소는 재확인합니다.
- 분리·해제 후 Windows의 실제 IP→MAC 고정 상태를 확인하고, 해제 확인에 실패하면 복구 기록을 유지합니다.
- 인터페이스 새로고침에 제어판에서 변경한 IPv4 설정을 반영합니다.
- DHCP 서버 확인, 최근 완료한 스캔의 미응답 IP 후보 목록, 연속 Ping, 단일 TCP 포트 확인을 제공합니다.
- 흰색·파란색을 유지하면서 목록 밀도와 버튼·대화상자 구성을 정리했습니다. SUIT Variable 글꼴을 로컬에 포함합니다.
- 로그는 하단에 고정하고 높이를 조절할 수 있습니다. 진행률은 작업 중 표시하며 완료 후 약 5초간 유지합니다.
- MAC 제조사 자료를 IEEE 공개 등록부로 갱신하고, 기존 사전의 제조사와 일치하는 새 앞자리를 추가했습니다. 새 앞자리는 제품 종류를 추정하지 않습니다.
- 경로 추적, 이름·모델 자동 수집, 스위치 관리와 보고서 기능은 포함하지 않습니다.

2026-11-13에 내려받은 IEEE 자료를 반영했습니다. 제조사 표는 59,134개 앞자리이며 기존 표에 663개를 추가했습니다. 장비 사전은 새 앞자리 1,047개를 추가하고 불완전한 기존 항목 1개를 제거해 총 3,667개 앞자리를 포함합니다. 기존 사용자 사전 파일은 덮어쓰지 않습니다.

## 설치

`Quiet.Scanner.Setup.4.0.0.exe`를 다운로드해 실행합니다.

- Windows 10/11 x64 전용입니다. 관리자 권한이 필요합니다.
- [Npcap](https://npcap.com)을 별도로 설치해야 합니다. 설치 파일에 드라이버를 포함하지 않습니다.
- WebView2 Runtime이 없으면 설치 과정에서 인터넷 연결이 필요합니다.
- 사용자 장비 사전과 분리 복구 기록은 `%LOCALAPPDATA%\Quiet Scanner\`에 저장합니다.

## 동작 범위

ARP 충돌 탐지와 장비 분리는 같은 L2 네트워크에서 동작합니다. 분리는 이 PC의 연결 대상 MAC을 고정하는 방식이며, 다른 PC나 장비의 IP 설정을 바꾸지 않습니다. 사용 가능한 IP 목록은 스캔에 응답하지 않은 **후보**입니다. 실제 배정 전 DHCP 범위와 예약 주소를 확인해야 합니다.

모든 제조사·드라이버 조합에서 검증한 것은 아닙니다. 공유된 PC에서 작업을 마치면 분리를 해제하고 결과를 확인하십시오.
